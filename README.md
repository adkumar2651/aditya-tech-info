## 🔍 Overview

**Aditya Tech Info** is a student-made tech buying guide built to help Indian buyers cut through the noise and make smarter decisions. Whether you're a student looking for a budget laptop, a gamer hunting for the best RTX machine, or someone upgrading to a flagship phone — this guide has you covered.

> 📦 **40+ Devices** curated · 💯 **100% Honest** picks · 🆓 **Free**, no signup needed

- 📱 **Smartphones Guide** — Budget to flagship, every major brand covered with real specs and honest opinions
- 💻 **Laptops Guide** — RTX-powered gaming beasts to slim student machines

## 🚀 Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/adkumar2651/aditya-tech-info.git

# 2. Navigate into the project
cd aditya-tech-info

# 3. Open in browser — no build step needed!
open index.html
```

> This is a static site — no dependencies or npm install required. Just open and go! ✅
